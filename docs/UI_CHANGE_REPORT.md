# UI Change Report

Mục tiêu là nâng cấp giao diện hiện tại mà không đổi mô hình chức năng.

### Header
Giữ nguyên logo, search, danh mục, trang chủ, đăng nhập, giỏ hàng, lịch sử và avatar dropdown; thay visual theo hướng premium tối giản với nền tối, accent vàng champagne và spacing nhất quán.

### Footer
Giữ nguyên nội dung showroom/chính sách/danh mục/kết nối; đồng bộ nền, typography, spacing và responsive.

### Account
Profile/sidebar/form chuyển về cùng visual language với storefront, border/radius/shadow đồng nhất.

### Responsive
Profile chuyển từ 2 cột sang 1 cột ở màn hình nhỏ; input full-width; address card/control tự wrap; footer xếp cột.
